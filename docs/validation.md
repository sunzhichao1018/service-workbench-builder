# 验证报告 · v1.1.0 跨平台版

验证日期：2026-10-26。所有行为测试使用临时目录中的合成文件，与原生服业务数据隔离。

## 结构与分发

- Skill 入口、名称、说明和 UI 元数据通过结构校验。
- 参考文档链接均可解析，Python 与前端脚本语法检查通过。
- 四份 CSV 模板仅包含表头；模板可实际生成空工作台，不补造业务记录。
- 分发目录不含 SQLite/数据库备份、来源业务文件、运行配置、旧系统凭据或个人绝对路径。

## 行为回归

`python3 -m unittest discover -s tests -v`：20 项全部通过，其中原业务引擎 10 项、新增跨平台入口 10 项。原引擎覆盖：

1. 中文 CSV、BOM、字段/枚举映射和明确默认值。
2. XLSX 日期、工作表选择、不受无关合并页影响、无缓存公式阻断。
3. 重复主键、缺失关联和错误导入不会创建工作台。
4. 服务计划、验收数量、逾期/按期完成、未来执行排除。
5. 缺失计划及零计划保留待确认，未知值不充当零。
6. 未确认执行覆盖范围时不生成虚假的零完成或履约率。
7. Decimal 金额、多币种、非实际金额及未来收支隔离。
8. 不规范逗号金额与交易/任务对象矛盾会阻断。
9. 完整快照重复刷新不翻倍，保留跟进，并创建备份。
10. 实际本机 HTTP 保存、审计、CSV 导出与公式防护、错误路径和跨来源写入拦截。

## 新增跨平台验证

- JSON 单请求/单响应协议、能力检查和中文/空格路径正常。
- 初始化→配置→建台→核对→私有下载打包的工具流程实际完成。
- 来源、绝对路径、.. 与符号链接越界会拒绝，未知动作/字段和非 JSON 覆盖保护有效。
- 完整快照刷新需明确 full_snapshot=true；私有下载包不混入来源文件或旧备份。
- 在临时的其他 Agent 目录实际安装后，引擎可独立运行；既有目录不覆盖、递归复制会阻止。
- 通用提示词可从共同源文件一致生成，无本机相对文档依赖；原生 ZIP 保持单一顶层技能目录。
- 平台支持说明按官方文档复核；未调用任何付费模型 API，未在豆包/DeepSeek 账户或云沙箱实测。不将本机测试称为厂商平台端到端验证。

## 新用户场景模拟

独立测试根据“单人课程交付工作台”的自然请求，仅提供一份中文任务 CSV，实际完成文件画像、字段映射、工作台生成和指标核对；不依赖对象表、财务表或原数据库。
